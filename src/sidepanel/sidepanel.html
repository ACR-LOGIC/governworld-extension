              How GovernWorld works & privacy details

              Why this is free

              GovernWorld is free because the obvious business model for software like this is the one that would have made it worthless. Every detection and redaction path in this extension runs on your own machine, which means there is nothing to meter, no inference to bill, and no user data to monetise.

              Who built it

              GovernWorld is built by ACR LOGIC, an independent project led by Andres Chavez Ramirez, working on privacy and security tooling.

              Page text and documents stay on your device

              • Installs with no install-time host permissions. Always-on paste mode adds optional site access only if you approve it and can be revoked anytime.
              • Detection, OCR (Tesseract WebAssembly), and PDF/DOCX/image redaction execute inside your browser with no external model or third-party AI service.
              • Staged documents are held only in the extension's private storage while you review them and deleted when cleared or redacted.

              How it works and how it runs

              Detection uses deterministic pattern matching across 24 categories (23 built-in plus custom rules), with configurable thresholds and compliance presets. Page masks render in a closed Shadow DOM overlay without altering the website; document redactions flatten into a new copy while keeping your original untouched.

              Before you rely on it

              GovernWorld is a free assistant, not a compliance guarantee. Always review redacted output before sharing it.

              Open-source libraries & license
              • Mozilla PDF.js Apache-2.0 Renders each PDF page to a bitmap so it can be scanned and redacted.
              • Tesseract & tesseract.js Apache-2.0 WebAssembly optical character recognition running locally with bundled traineddata.
              • pdf-lib MIT Builds the flattened PDF output with redactions baked into the page content.
              • mammoth BSD-2-Clause Extracts text from Word .docx files for scanning.

              Feature guides & step-by-step instructions (21 topics)

              Overview

              GovernWorld protects sensitive data locally on your device across three workflows: live webpage scanning & masking, in-page Paste Shield for AI chats and forms, and Document Studio redaction for PDFs, Word files, and images.

              Local Mode

              Fresh installs boot in standalone LOCAL mode with zero network connections, zero alarms, and zero heartbeats. Page text and documents stay on this device. Only if you opt into organizational MANAGE pairing (via 6-digit code or OS policy) does the extension pull signed policies, lock admin security baselines while leaving accessibility settings editable, and run 15-minute metadata-only health checks.

              Page Scan — How to Scan a Webpage

              1. Open any regular http:// or https:// webpage.
              2. Click Scan This Page in the Protection tab (or press Alt+Shift+S).
              3. Review the Compliance Risk Scorecard (0–100) and the list of detected findings.
              4. Check or uncheck individual findings, then click Apply Masks, Copy Redacted, or Export (CSV/JSON).

              Masking — How Live Page Masks Work

              1. After scanning a page, keep the checkboxes checked for values you want to hide on-screen.
              2. Click Apply Masks (or press Alt+Shift+M) to draw non-destructive Shadow DOM privacy blocks over the page before screen-sharing or taking screenshots.
              3. Use Undo to revert the last mask change, Remove All to clear overlays, or Copy Redacted to copy text with sensitive values replaced by [REDACTED].

              Document Redaction — Step-by-Step Studio Guide

              1. Drag and drop a PDF (.pdf), Word (.docx), or Image (.png, .jpg, .webp) up to 20 MB into the upload box (in Popup mode, GovernWorld automatically opens the persistent Side Panel so the file picker never closes your session).
              2. For documents over 20 pages, choose which 20-page window to scan first.
              3. Click findings on page thumbnails to toggle them, or use ✏️ Draw Box to drag custom redaction boxes. Draw boxes on 3+ pages and click 📍 Learn Location Rule to save a reusable coordinate rule.
              4. Select Blackout, Whiteout, or Text Stamp, then click Open full-screen review or Redact & Download to save a flattened, pixel-verified copy.

              Verification & Compliance Certificates

              1. When you redact a document, GovernWorld re-reads the rendered output pixels to confirm every selected region is covered before declaring it verified.
              2. In the Review tab, check the Coverage grid to see whether all page content, images, and OCR regions were inspected.
              3. Click Export signed audit log to download the ECDSA P-256 signed .jsonl log, .sig.json signature, and printable Compliance Certificate.

              Wizard — Creating Custom Detection Rules

              1. Go to the Logic tab and click + Create Personal Logic.
              2. Step 1: Paste 2 or more positive examples (one per line, e.g. EMP-104928) or click Import File ↗, plus optional negative examples that should NOT match, then click Analyze.
              3. Step 2 & 3: Select a proposed regular expression and test it live against sample text.
              4. Step 4: Enter a Rule Name, Category, Confidence threshold (0–1), optional Context Cues (nearby keywords), and Min/Max length, then click Save Rule.

              Categories & Confidence Thresholds (24 Detectors)

              Includes 24 detection categories (23 built-in plus custom rules) across PII, HIPAA/PHI (MRN, NPI, DEA, MBI), financial (Luhn payment cards, bank accounts, CUSIP/ISIN/IBAN), international IDs (SIN, NHS, Aadhaar, PAN, TFN, CPF), and developer secrets. In Settings → Detection, pick a compliance preset (HIPAA, PCI DSS, GDPR, etc.), toggle categories, and set per-category confidence thresholds.

              Paste Guard — Protecting AI Prompts & Forms

              1. This Tab (Default): Requires zero install-time host permissions; activates on the current tab once you open or scan with GovernWorld.
              2. Always On: Toggle Always protect all sites in Settings → Protection and approve the browser site-access prompt (revocable anytime) to guard every tab automatically.
              3. When you paste sensitive data into ChatGPT, Claude, Gemini, Slack, or web forms, Paste Shield pauses the paste and lets you choose Sanitize & Paste, Paste Unchanged, or Cancel.

              Context Menus — Right-Click Actions

              1. Highlight any text on a webpage and right-click to open the browser context menu.
              2. Choose Scan page for sensitive data, Redact selection to clipboard (copies sanitized text with [REDACTED]), or Mask selected text (covers the selection in-place).
              3. Enable or disable right-click menus anytime in Settings → Protection → Context Menu Protection.

              OCR Languages

              English (eng) in this build. Additional languages can be added by bundling their traineddata; nothing is downloaded at runtime. Select your bundled OCR language in Document Studio or Settings → Advanced before scanning image-based PDFs or screenshots.

              Redaction Styles — Blackout, Whiteout & Stamp

              Choose how redacted boxes are baked into downloaded documents: Blackout (solid opaque black rectangle), Whiteout (solid white box with subtle border), or Text Stamp (opaque box stamped with [REDACTED], [CONFIDENTIAL], [PHI REMOVED], or custom text). Set your default style in Settings → Protection.

              Accessibility — Vision, Motion & Screen Readers

              In Settings → Appearance & Accessibility, customize Text Size (Default to Extra Large), High Contrast borders, Dyslexia-Friendly Mode spacing, Reduced Motion, Speech Announcements (Web Speech API audio readouts), and Verbose ARIA Mode.

              Languages — 7 Localized UI Languages

              Switch the entire interface instantaneously in Settings → Appearance & Accessibility → Language between English, Español, Français, Deutsch, 日本語, Português, and 简体中文.

              Notifications & Zero-Knowledge Privacy Mode

              Configure how alerts appear across icon badges, in-page toasts, and desktop notifications without leaking sensitive data. Switch Notification Privacy Mode to Minimal to hide category names from alert banners.

              Settings — Navigating All 8 Sections

              Use the top-right circular Profile Avatar menu or the Settings tab to access: Profile & Account (Office Manager pairing, Enterprise Device Enrollment, OAuth/API), Protection, Detection (presets, 24 categories, confidence thresholds), Appearance, Notifications, Privacy, Advanced (scan limits & OCR), and About & Diagnostics.

              Shortcuts — Keyboard Hotkeys

              Press Alt+Shift+S to scan the active page, Alt+Shift+M to toggle visual masks on/off after a scan, and Alt+Shift+P to open the persistent Side Panel workspace. Customize shortcuts at chrome://extensions/shortcuts.

              Troubleshooting — Common Questions

              • Scan says restricted or unavailable: Browser internal pages (chrome://, edge://, about:, Chrome Web Store) block extensions by browser security policy. Test on any regular https:// website.
              • Page has 0 characters: The page is likely a scanned image or canvas; use the offered Capture Image to Document Studio button to run local OCR.
              • Paste Shield says Waiting for access: Click the Paste Shield pill or Grant site access in Settings → Protection to approve browser host permissions.

              Cloud & Enterprise Coordination

              Cloud analysis is disabled by default so all page and document scanning runs locally on your device. Optional Organization Gateway, OAuth, and Office Manager pairing in Settings → Profile & Account pull Ed25519-signed compliance policies and emit 15-minute metadata-only status checks (device UUID, browser info, extension/policy versions) while keeping accessibility controls unlocked and transmitting zero browsing history, URLs, page text, or documents.

              Privacy & Zero-Egress Guarantee

              Page text and documents stay on this device. Findings store only masked previews (e.g. ***-**-4829), and staged document bytes are wiped when cleared, after redaction, or on browser startup.
