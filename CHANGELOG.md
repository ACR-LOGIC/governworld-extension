## [0.4.1] — Directive GW-DEV-DIRECTIVE-2026-001

- **C2**: Verified automatic service-worker startup orphan purge (`purgeOrphanedStagedKeys` deletes orphaned staged keys while keeping active live-session keys intact) and added `getStagedStorageAudit()` / `purgeStagedData()` (`POPUP_GET_STAGED_STATS`, `POPUP_PURGE_STAGED_DATA`, `POPUP_STAGED_STATS_STATE`) plus the Document Studio **Staged data** audit bar (`#doc-staged-audit`, `#doc-staged-summary`, `#doc-purge-staged-btn`, inline `#doc-purge-confirm-bar`, `#doc-staged-confirm-msg`) across all 7 locales and synced `sidepanel.html`.

- **C1 (D5)**: Implemented all Section 4 measured gates (`G1`–`G9`) as blocking hard failures (`exit 1`, zero warnings or skips) via `scripts/run-ci-gates.mjs` (`npm run gates:ci`), recorded official performance budgets (`1.20x` ceiling over `125.6 ms`, `42.0 ms`, `50.0 ms`) in `docs/benchmarks/ci-baselines.json`, added `tests/redaction-golden-gate.test.ts` (`G4`) and `tests/export-secret-recovery-gate.test.ts` (`G5` 3-way finished-PDF re-decode via `pdf-lib`, `pdfjs-dist`, and XObject RGB pixel verification), wired blocking `xvfb-run --auto-servernum npm run gates:ci` steps into `.github/workflows/ci.yml` and `.github/workflows/release.yml`, and proved every single gate `G1`–`G9` fails (`exit 1`) when deliberately broken and passes (`9/9`) when restored.

- **P12**: Audited all 127 test files and replaced every vacuous constant check, no-op branch, inline pre-fix bug simulation, and overlap-only recall assertion across 7 files (`tests/e2e-audit-tier2-boundaries.test.ts` B5.1–B5.5 & B6.1, `tests/e2e-audit-tier1-features.test.ts` F7.1–F7.2, `tests/e2e-audit-tier4-scenarios.test.ts` Scenario 1 step 3, `tests/content.test.ts` Feature 7, `tests/adversarial-m2-rescan.test.ts` Challenges 1/2/5, `tests/detection-benchmark.test.ts` Unicode email + exact-span matching, and `tests/offline-assets.test.ts`), documented the Anti-Vacuity Policy in `CONTRIBUTING.md`, updated `docs/benchmarks/GW-BENCH-2026-001-RECORD.md`, and proved fail-on-revert behavior by temporarily reverting P1 (`6/101` failures, exit `1`) and P2 (`2/15` failures, exit `1`).

- **P11**: Established `package.json` (`"version": "0.4.1"`) as the single source of truth via `scripts/sync-version.mjs` (`npm run sync:version` / `npm run sync:version:check`), synchronized `package-lock.json`, `manifest.json`, `manifest.firefox.json`, `src/api/config.ts`, `src/landing/index.html`, `src/popup/privacy.html`, `README.md`, and `AGENTS.md`, added `#diag-version-value` (`diag_version` in all 7 locales) in **Settings → About & Diagnostics** driven from `chrome.runtime.getManifest().version || CURRENT_EXTENSION_VERSION`, wired `npm run sync:version:check` as a hard CI failure in `.github/workflows/ci.yml` and `release.yml`, and proved both CLI and `tests/version-parity.test.ts` exit `1` on deliberate version drift.
- **P7**: Implemented adaptive mutation debounce (option (a)) across `src/content/normalization/mutation.ts` (`SMALL_BATCH_NODE_THRESHOLD = 10`, `FAST_DEBOUNCE_MS = 16`, `BURST_DEBOUNCE_MS = 150`) and `src/content/content.ts` (`SMALL_BATCH_RESCAN_DELAY_MS = 20`, retaining `BURST_RESCAN_DELAY_MS = 500` for bursts `> 10` nodes; also filtering internal `[data-gw-scan-overlay]` / toast nodes from triggering redundant rescans). Live Chrome 159 latency dropped from `~679 ms` to **`54.4–61.7 ms` (`p50 57.1 ms`)** across `5/5` `characterData` edits and `61.3–62.8 ms` (`p50 61.7 ms`) across `3/3` added-node controls (all well under `< 250 ms`), while preserving `500 ms` burst coalescing.
- **P6 (D4)**: Replaced the 250,000-character whole-page truncation cut-off with chunked windowed scanning (`extractVisibleTextWindows` / `buildCanonicalDocumentWindows` + `chunkFindingsByByteBudget`): scans full pages across consecutive windows (keeping `maxVisibleChars` as a per-window memory safeguard only, default 200-window technical ceiling explicitly disclosed), emits live `SCAN_PROGRESS` -> `POPUP_SCAN_PROGRESS` progress updates, chunks findings past 48 KB across both Chrome IPC hops (`SCAN_RESULT_CHUNK` + `POPUP_STATE_CHUNK`) within `MAX_MESSAGE_BYTES` (64 KB), and renders explicit window coverage / incomplete-window statements in popup/sidepanel UI across all 7 locales (`10,000`-node page now returns **`300/300`** findings across `4` windows in both Run 1 and live Chrome 159).
- **P5**: Updated `EMAIL_RE`, `detectEmails`, and `maskValue("email")` in `src/content/detect.ts` and `isMaskedPreview("email")` in `src/shared/messages.ts` to support Unicode letters/numbers without stripping accents (option (a)), raising Run 1 strict exact-span recall from `21/22 (95.5%)` to **`22/22 (100%)`** (`misses: []`; `josé.maría@example.test` matched cleanly at exact offsets; `1 MB detect p50 = 112.104 ms`; live Chrome `2/2` accented email masks).
- **P3**: Incremental DOM rescans in `src/content/content.ts` now emit updated `SCAN_RESULT` messages via `emitScanResult()` with current session stats, and `handleContentScanResult()` in `src/service-worker/index.ts` accepts matching active-session incremental results when no `pendingScans` entry is open, pushing `POPUP_STATE` and calling `updateBadgeForTab()` (`5/5` live Chrome trials synchronized: `session=1`, `badge="1"`, `popup=1`).
- **P4**: Implemented full staged-document prefix deletion (`docDeleteByPrefix` / `deleteDocBytesByPrefix`), cooperative `AbortController`/`AbortSignal` + offscreen `"cancel"` cancellation through `pdf.ts`/`ocr.ts`/`impl.ts`/`browser.ts`, orphan-only startup purge (`purgeOrphanedStagedKeys`), and truthful popup cancelled state (`Start Over` leaves `0` keys across 1/5/20p; mid-job `Cancel` stops OCR/key growth within 1 s and leaves `0` keys).
- **P2**: Eliminated the `rescan_seg_0` segment/finding ID collision in `src/content/content.ts` by introducing session-scoped monotonic `nextRescanSegId` (`rescan_seg_<N>`) and `nextRescanFindingSeq` (`rescan_<cat>_<N>`) counters reset on `clearSession()` (`3/3` live Chrome batch-removal trials left `0` ghost masks and kept surviving Email/SSN masks aligned).
- **P1**: Fixed the `characterData` mutation blind spot in `src/content/content.ts` (`rescanAffectedRegions`) and `src/content/extract.ts`: in-place text-node edits now re-extract, re-detect (with `enrichAndBoostNames`), rebase surviving findings' combined offsets after segment splices, merge coalesced mutation batches, clear pending batches in `clearSession()`, and update/clear overlay masks cleanly (`5/5` live Chrome trials masked in `669.2–694.1 ms`, `p50 679.2 ms`).
- **Phase 0**: Confirmed baseline at commit `da2024e6aae8f1906c9f9743ce3c8821751cafa1`, added reproducible Run 1 (`tests/benchmark-measured.test.ts`) and Run 2 (`scripts/run2-driver.mjs`) benchmark harnesses, created root `CHANGELOG.md`, benchmark record (`docs/benchmarks/GW-BENCH-2026-001-RECORD.md`), and directive tracking checklist (`docs/releases/DIRECTIVE_GW-DEV-DIRECTIVE-2026-001_CHECKLIST.md`).
