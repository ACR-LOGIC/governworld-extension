# Task Report — P4: Staged Document Prefix Deletion & Cooperative Cancel Abort

## 1. Task ID and title
**P4** — Cancel / Start Over leave staged bytes; Cancel does not stop OCR (Option (a), all three parts together).

## 2. What changed
- **Before:** Clicking **Start Over** deleted only the bare document key (`fileKey`), leaving every derived `::preview::` and `::page::` IndexedDB key behind (`2`, `10`, and `40` surviving keys after 1-, 5-, and 20-page documents). Clicking **Cancel** mid-job failed to send a cancel message before `docId` existed, sent no offscreen abort signal, allowed Tesseract/OCR loops to run to completion, and could allow late completion messages into the popup.
- **After:** Implemented all three parts of Option (a):
  1. **Enumerate & delete all keys for the document (`src/shared/docDb.ts`, `src/shared/docStore.ts`, `src/service-worker/documents.ts`, `src/shared/types.ts`, `src/shared/messages.ts`):** Added `docListKeys()`, `docDeleteByPrefix()` (with optional `{ keepRedacted: true }` strictly for post-download print preview), `docGetStagedStats()`, `listDocKeys()`, and `deleteDocBytesByPrefix()`. Extended `POPUP_DOC_CANCEL` and `POPUP_DOC_CLEAR` to accept `docId` or `fileKey`. Both **Cancel** and **Start Over** remove the base key plus every derived `::preview::`, `::page::`, `::redacted::`, and `::redacted-manifest` key.
  2. **Cooperative `AbortController` / `AbortSignal` (`src/document-pipeline/contract.ts`, `ocr.ts`, `pdf.ts`, `impl.ts`, `browser.ts`, `src/offscreen/offscreen.ts`):** Added `DocumentCancelledError` and offscreen `"cancel"` operation. Abort signals are checked across `renderPdfPages`, per-page OCR inside `ocrCanvas` (terminating Tesseract via `resetOcr()` on abort), and per-page `putDocBytes` staging in `runDocumentPreview`.
  3. **Orphan startup purge & truthful UI (`src/service-worker/documents.ts`, `src/service-worker/index.ts`, `src/popup/popup.ts`, `src/popup/index.html`, `src/sidepanel/sidepanel.html`):** Added `purgeOrphanedStagedKeys()` on service-worker startup (deleting unreferenced IndexedDB prefixes while preserving live-session documents). Updated popup **Cancel** to send `POPUP_DOC_CANCEL` even before `docId` exists, drop late `POPUP_DOC_STATE`/`COUNT_RESULT`/`STATUS`/`ERROR` updates for cancelled tokens, and always display `"Document processing cancelled."` with the workspace hidden.
