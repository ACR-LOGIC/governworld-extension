# S6 Task Report — Task C3: Prominent Popup Coverage Warnings for Unscannable Regions

## 1. Task ID and title
**Task C3 — Coverage warnings in popup (incomplete window, truncation, cross-origin iframe, closed shadow root, canvas-only page)**

---

## 2. What changed — behaviour before and after, in plain language
- **Before:** When a scan encountered unscannable regions on a page — such as an incomplete window at the 200-window technical ceiling, a cross-origin `<iframe>`, a closed Shadow DOM root (`attachShadow({ mode: "closed" })`), or a canvas-only page with zero extractable DOM text — the popup showed the general scan summary and collapsible coverage checklist, or only a single-line truncation warning, without a prominent top-level warning banner naming every specific unscannable region cause alongside the findings count from the scanned portion of the page. Furthermore, when `chrome.dom.openOrClosedShadowRoot` was unavailable, closed shadow roots attached by page scripts were not counted in the page inventory.
- **After:**
  1. **Closed shadow root detection (`src/content/normalization/shadow.ts` & `src/content/normalization/pageInventory.ts`):** Added a lightweight `WeakSet<Element>` hook on `Element.prototype.attachShadow` (`init.mode === "closed"`) and `isRecordedClosedShadowHost(element)` so closed shadow hosts are inventoried (`closedShadowRootsBlocked`) even when `chrome.dom.openOrClosedShadowRoot` is unavailable, while excluding GovernWorld's own injected UI hosts (`[data-gw-scan-overlay]`, `[data-gw-toast-host]`, `[data-gw-paste-guard]`, `[id^="__governworld-"]`) from the page inventory.
  2. **Structured `coverageWarnings` (`src/shared/types.ts`, `src/shared/messages.ts`, `src/content/content.ts`, `src/service-worker/index.ts`):** Added `CoverageWarningCause` (`"incomplete_window" | "truncated" | "cross_origin_iframe" | "closed_shadow_root" | "canvas_only"`) and `CoverageWarning` (`{ cause, count, detail? }`). `handleScan` in `src/content/content.ts` populates `coverageWarnings` whenever any of those conditions occurs and degrades `coverageStatus` from green (`FULLY_SCANNED` / `NO_SENSITIVE_DATA_DETECTED`) to `PARTIALLY_SCANNED` (or `BLOCKED_BY_BROWSER_SECURITY` for cross-origin iframes).
  3. **Prominent popup warning banner (`src/popup/index.html`, `src/popup/popup.css`, `src/popup/popup.ts`, `src/shared/i18n.ts`, `src/sidepanel/sidepanel.html`, `src/sidepanel/sidepanel.css`):** Added `#coverage-warnings-banner` (`class="coverage-warning-banner"`, `role="alert"`) inside `#scan-summary` with `#coverage-warnings-findings-count` (`X finding(s) in scanned regions`) and `#coverage-warnings-list` (one `li[data-cause]` item per warning cause, localized across all 7 UI languages: `en`, `es`, `fr`, `de`, `ja`, `pt`, `zh`). On a clean HTML page with no unscannable regions, `#coverage-warnings-banner` remains hidden (`hidden = true`).
