# Task Report — P6: Chunked Windowed Full-Page Scanning (Decision D4)

## 1. Task ID and title
**P6 (Decision D4)** — 250,000-character scan cap truncates large pages (replaced whole-page cut-off with chunked windowed scanning, live progress, explicit coverage statement, and `<= 64 KB` IPC findings chunking).

## 2. What changed
- **Before:** Both `extractVisibleText` (`maxVisibleChars = 250,000` default) and `capFindingsForTransport` (48 KB slice drop) cut off large pages mid-scan: a 10,000-node page returned only `87` of `300` expected findings in Run 1, showed no scanning window progress in the popup, and dropped findings past 48 KB when transported over Chrome runtime messaging.
- **After:** Implemented option (a) per Decision D4:
  - **Windowed whole-page extraction (`src/content/extract.ts`, `src/content/normalization/canonical.ts`):** Added `extractVisibleTextWindows` and `buildCanonicalDocumentWindows`, keeping `settings.maxVisibleChars` (`250,000` default) strictly as a per-window memory safeguard rather than a whole-page cut-off. Traversal continues across consecutive windows up to `DEFAULT_MAX_TOTAL_WINDOWS = 200`; reaching that technical ceiling stops cleanly, sets `hardLimitReached = true`, and records `{ windowIndex, reason }` in `incompleteWindows` (never reported as clean).
  - **Windowed scan loop & live progress (`src/content/content.ts`, `src/service-worker/index.ts`, `src/popup/popup.ts`):** `handleScan` scans every window with per-window failure isolation, yields only between windows when `windowsTotal > 1` (0 ms overhead on 1-window scans), emits `SCAN_PROGRESS` -> `POPUP_SCAN_PROGRESS` with windows/chars/findings completed, and updates `#status` and `#summary-chars` live in the popup.
  - **Lossless `<= 64 KB` IPC chunking (`src/shared/messages.ts`, `src/shared/types.ts`):** Added `chunkFindingsByByteBudget` and validated `SCAN_RESULT_CHUNK` + `POPUP_STATE_CHUNK` across both IPC hops (`content -> service worker -> popup`) while preserving `MAX_MESSAGE_BYTES = 64 KB` (`tests/doc-preview-transport.test.ts`). Missing chunks force `truncated: true`, `coverageStatus: "PARTIALLY_SCANNED"`, and an incomplete-window notice.
  - **Explicit coverage statements & Settings copy (`src/popup/index.html`, `src/popup/popup.ts`, `src/shared/i18n.ts`, `src/sidepanel/sidepanel.html`):** Added `#scan-coverage-statement` and `#coverage-windows-detail` reporting either `"All X of X windows scanned (N characters)."` when complete or naming every unscanned window and reason when incomplete. Updated `max_visible_chars_label` and `max_visible_chars_hint` across all 7 locales and synced sidepanel HTML.
