## 2. What changed — behaviour before and after, in plain language
- **Before:** The service worker resolved scan and mask commands via `getActiveTab()` across three active-tab fallback strategies, and the popup's Scan button called `getActiveWebTab()`. If focus shifted to another tab during a workflow, scan and mask commands could target a different tab than the one the user intended.
- **After:**
  1. **Explicit Pinned Scan Target (`src/service-worker/index.ts`, `src/shared/types.ts`, `src/shared/messages.ts`):** Added `PinnedTargetStatus` (`"unpinned" | "pinned" | "navigated" | "closed"`), `ScannableTabSummary`, `PinnedTargetInfo` on `PopupState`, and `POPUP_PIN_TAB` (`{ type: "POPUP_PIN_TAB", requestId, tabId, pinCurrent? }`). Once a tab is pinned in `chrome.storage.session` (`pinnedScanTarget`), all scan, rescan, finding, badge, and overlay operations bind strictly to `pinnedTabId` until the user changes it or the tab closes. Tab focus changes are never auto-followed, and no opt-in "follow active tab" mode was built (Decision D2).
  2. **Navigation & Close Handling (`chrome.tabs.onUpdated` & `chrome.tabs.onRemoved`):**
     - When the pinned tab navigates to a new URL, the pin stays on `pinnedTabId`, updates the displayed title/domain/URL, and sets `status: "navigated"`.
     - When the pinned tab closes, the pin is cleared (`pinnedTabId: null`), `status` transitions to `"closed"` (preserving `closedTitle` / `closedDomain`), and the service worker falls back to **no scan** (`code: "TARGET_TAB_CLOSED"`) until the user selects a new target tab.
  3. **Synchronous background-tab overlay paint (`src/content/overlay.ts`):** Updated `overlay.render(items)` to paint synchronously so masks applied to a pinned tab while another tab is focused in the foreground are immediately painted into the shadow-root overlay without waiting for foreground `requestAnimationFrame`.
  4. **Popup Pinned Target Header Bar (`src/popup/index.html`, `src/popup/popup.css`, `src/popup/popup.ts`, `src/shared/i18n.ts`, `src/sidepanel/sidepanel.html`, `src/sidepanel/sidepanel.css`):** Added `#pinned-target-bar` directly below the popup header displaying `#pinned-target-title`, `#pinned-target-domain`, the `#pinned-tab-select` target tab picker listing all open scannable tabs, the one-click `#pin-current-tab-btn` (`Pin current tab`) button, and the `#pinned-target-warning` alert banner (shown when unpinned, navigated, or closed). Disables **Scan** (`#scan-btn`) and **Apply Masks** (`#apply-masks-btn`) whenever no target tab is pinned (`pinnedTabId === null`), localized across all 7 UI languages (`en`, `es`, `fr`, `de`, `ja`, `pt`, `zh`).
