# Task Report — P2: Unique Session-Scoped Segment IDs & Ghost Mask Elimination

## 1. Task ID and title
**P2** — `rescan_seg_0` collision and ghost masks (session-scoped unique segment & finding identifiers, option (a)).

## 2. What changed
- **Before:** Every incremental call to `appendAndDetectNode` inside `src/content/content.ts` prefixed `rescan_` onto `extractVisibleText`'s local counter (which restarts at `seg_0` on every call), so every incrementally added or edited node collided on `rescan_seg_0`, overwriting `nodeIds` and `segmentIndexById`. Removing the first element of a three-node batch (`NPI`, `email`, `SSN`) left all three masks visible including a ghost NPI mask (`3/3` trials).
- **After:** Implemented option (a):
  - Added session-scoped monotonic counters `nextRescanSegId` and `nextRescanFindingSeq` in `src/content/content.ts`, reset on `clearSession()`.
  - Each incrementally extracted segment now receives a globally unique session-scoped `nodeId` (`rescan_seg_${nextRescanSegId++}`), and each incremental finding receives a collision-free session-scoped `id` (`rescan_${nf.category}_${nextRescanFindingSeq++}`).
  - Removing or editing one node removes only that node's segment, findings, and overlay mask while surviving nodes stay accurately mapped and rebased.
