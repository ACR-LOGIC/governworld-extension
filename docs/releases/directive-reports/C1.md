## 1. Task ID and title

**C1** — Measured gates in CI as hard failures [Decision D5: APPROVED]

## 2. What changed — behaviour before and after

- **Before:** CI (`.github/workflows/ci.yml` and `.github/workflows/release.yml`) ran unit tests, typecheck, sidepanel sync, security lint, and version parity, but did not enforce the Section 4 measured benchmark and live-browser gates (`G1`–`G9`) as blocking CI failures. As a result, overlap-only recall hid the Unicode email miss (`P5`/`G1`), vacuous constant checks hid the live `characterData` blind spot (`P1`/`G3`), and no automated gate checked `<= 20%` performance regression (`G9`) or re-decoded finished PDF exports for secret/pixel recovery (`G5`).
- **After:** Implemented `scripts/run-ci-gates.mjs` (`npm run gates:ci`) and wired it as a mandatory blocking step (`xvfb-run --auto-servernum npm run gates:ci`, zero `continue-on-error` or skips) into `.github/workflows/ci.yml` and `.github/workflows/release.yml`. Recorded the official baselines (`detect1MbP50Ms: 125.6`, `scan1kP50Ms: 42.0`, `pasteDialogP50Ms: 50.0`, `maxRegressionRatio: 1.2`) and hard limits (`200 ms`, `75 ms`, `100 ms`, `2000 ms`) in `docs/benchmarks/ci-baselines.json`. Added `tests/redaction-golden-gate.test.ts` (`G4`) and `tests/export-secret-recovery-gate.test.ts` (`G5` three-way finished-PDF re-decode via `pdf-lib`, `pdfjs-dist`, and embedded RGB XObject pixel inspection). Every single gate `G1`–`G9` was deliberately broken in turn, proven to fail (`exit 1`), and restored.
