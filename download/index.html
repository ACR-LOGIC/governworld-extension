Cryptographic Integrity

Verify the hash before you install

The SHA-256 hash is a unique fingerprint of the sealed file. Comparing your downloaded file against the hash above proves the file was not changed.

For Windows

Open PowerShell and run Get-FileHash governworld-v0.5.0.crx -Algorithm SHA256, then compare it to the hash above.

Get-FileHash governworld-v0.5.0.crx -Algorithm SHA256
For Mac

Open Terminal and run shasum -a 256 governworld-v0.5.0.crx, then compare it to the hash above.

shasum -a 256 governworld-v0.5.0.crx
For Android

Verify on desktop if you can. The hash above is the same file from the GitHub release.

Install steps

1Windows, Chrome or Edge

  1. Click Download GovernWorld Extension.
  2. When Chrome asks to install, click Add extension.
  3. Confirm the hash matches if you want to verify first.

2Mac, Chrome or Edge

  1. Click Download GovernWorld Extension.
  2. When Chrome or Edge asks to install, click Add extension.
  3. Confirm the hash matches if you want to verify first.

Safari on Mac does not support Chrome extensions. Use Chrome or Edge.

3Android, Chrome

  1. Open this page in Chrome on Android.
  2. Tap Download GovernWorld Extension.
  3. Tap Install app or Add to Home Screen when prompted.
